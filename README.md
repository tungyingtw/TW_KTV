# TYFunLab KTV 歌曲查詢

TYFunLab KTV 歌曲查詢是一個整理台灣常見 KTV／伴唱平台現場收錄狀態的查詢網站，協助使用者快速確認歌曲是否可能被不同平台收錄，以及是否具備原版 MV、導唱等現場資訊。

網站資料以公開可查詢資料、站方整理資料與使用者回報線索作為參考。由於各 KTV 門市、伴唱系統與曲庫版本可能不同，實際可點唱狀態仍以現場設備顯示為準。

## 主要功能

- 搜尋歌名、歌手與點歌相關資料
- 依語種、字數、平台與收錄狀態篩選歌曲
- 查看各 KTV／伴唱平台的收錄、導唱與 MV 類型參考
- 提供歌曲資料建議與現場狀態回報
- 收藏常查歌曲至本機歌本
- 提供小遊戲頁面作為附加互動內容

## 資料聲明

本網站不提供、儲存或散佈任何未授權音訊、影片、歌詞全文或盜版影音內容。站內如出現 YouTube 等第三方影音平台連結，僅作為官方或公開來源參考，相關內容版權屬原權利人與發布平台所有。

歌曲收錄、導唱、MV 類型與點歌資訊可能因平台版本、門市設備、授權狀態或資料更新時間而有所差異。使用者應以實際 KTV 現場設備資訊為準。

## 技術

本專案以前端網頁為主，使用 React、TypeScript 與 Vite 建置。

## 歌庫首載

建置時產生 `songs_catalog.compact.bin`：先 gzip 壓縮 JSON，再套用既有 XOR 混淆，使用 `TWKTVGZ1` 標頭。混淆不是存取控制。瀏覽器依 manifest 優先下載壓縮檔、驗證 SHA-256，並由 Worker 解壓與解析；不支援原生解壓或下載驗證失敗時使用原有分片。部署時一併發布 manifest、新檔與原有分片。

歌庫下載與修正資料同步並行；介面先顯示可用歌庫與上次成功同步的修正，後端回應後套用更新及刪除。同步逾時為 12 秒，不阻擋查歌。資料就緒後不等待進度動畫。

執行 `npm run test:catalog` 驗證格式一致、損壞備援及背景同步；執行 `npm run qa:mobile-first-load` 檢查資源與首載防護。

2026-09-14 本機驗證：109,363 首完整資料由 16,164,204 bytes 降為 2,528,145 bytes（減少 84.4%）。以同版正式建置、不同來源隔離快取，伺服器每 100ms 傳送 125,000 bytes 模擬 10 Mbps，首次結果出現時間為原始分片 15.205 秒、壓縮檔 3.157 秒。這是單次桌面瀏覽器測試，未模擬手機 CPU、行動網路延遲或正式站 CDN；不是正式站速度保證。
