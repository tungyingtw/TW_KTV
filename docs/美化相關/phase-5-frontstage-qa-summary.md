## 已驗證畫面

- 驗證 desktop dark 首頁、搜尋列、品牌列、列表模式。
- 驗證 desktop light 首頁、搜尋列、品牌列、列表模式。
- 驗證 mobile dark 首頁、搜尋列、品牌列、列表模式。
- 驗證 mobile light 首頁、搜尋列、品牌列、列表模式。
- 驗證手機矩陣列表欄位為「歌曲 / 收錄 / MV / 導唱」。
- 驗證歌曲詳情 modal 不透底，且層級高於列表互動回饋。
