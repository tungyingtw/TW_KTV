# 雀歌開局

單人台灣 16 張麻將 Web 小遊戲，玩家對三名電腦玩家，包含代幣、底注、電腦難度、代打、吃碰槓胡與結算流程。

## 正式掛載內容

- `index.html`：正式遊戲頁。
- `src/`：遊戲流程、規則、AI、渲染、音效與特效模組。
- `assets/`：麻將牌圖、桌面圖像與音效素材。

- 回到小遊戲列表：`../`
- 回到主查歌頁：`../../`
