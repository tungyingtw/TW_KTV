# 雀歌開局

單人休閒台灣 16 張麻將 Web 小遊戲，玩家對三名電腦玩家，包含代幣、底注、電腦難度、代打、吃碰槓胡與結算流程。台灣 16 張是正式主玩法，13 張練習模式只提供簡化練習，不代表完整日麻或港麻規則。

## 正式掛載內容

- `index.html`：正式遊戲頁。
- `src/`：遊戲流程、規則、AI、渲染、音效與特效模組。
- `assets/`：麻將牌圖、桌面圖像與音效素材。

## 固定休閒桌規

- 放槍由放槍者付款，自摸由其餘三家逐筆付款；電腦互相放槍不變更玩家代幣。
- 每筆金額為 `底注倍率 ×（台型＋莊家收付＋本場）`，不是另收底錢再逐台加價。莊家參與的該筆加 1 台與每本場 1 台，不採連 N 拉 N；餘額不足時只扣實際餘額。
- 七搶一為基本胡 1＋特殊 8 台，由持有第八花的玩家付款；八仙過海為基本胡 1＋特殊 16 台，由其餘三家付款。兩者仍依付款關係加莊家與本場。
- 胡優先於碰／槓，碰／槓優先於吃；吃只能吃上家。玩家可胡時先選胡或過，過後按電腦索引裁定單一贏家。
- 座位門風與正花固定，圈風依局數更新。牌山不留尾墩：最後摸牌仍可自摸或打出，最後棄牌只可胡或過。
- 一般補花後自摸不另算槓上開花；槓後補牌自摸才算槓上開花。
- 本遊戲是固定休閒規則，不含過水、振聽、完整多家同胡或地方桌規切換。
